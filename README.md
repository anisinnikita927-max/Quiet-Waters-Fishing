# Quiet Waters: Fishing

Спокойная 3D-рыбалка от первого лица на Godot 4.7. Одиннадцать озёр с живой погодой, музыкой и своей рыбой, магазин из двенадцати удочек и коллекция из 32 видов рыб. Весь мир собран из округлых форм: шаров, капсул и торов.

## Как играть

- В **главном меню** выбери «Играть», «Озёра», «Магазин удочек», «Коллекция рыб» или «Настройки».
- Зажми левую кнопку мыши (или палец), чтобы зарядить заброс, и отпусти её.
- Дождись поклёвки — поплавок дёрнется, — и нажми ещё раз для подсечки.
- Во время вываживания удерживай кнопку, чтобы подтягивать рыбу; отпускай, если кольцо вокруг прицела краснеет (натяжение выше 75%). Внутренняя дуга кольца показывает, насколько рыба уже подтянута.
- Пойманная рыба выпрыгивает из воды, зависает перед тобой и улетает в коллекцию. За улов начисляются монеты, а за новый вид — бонус.
- Кнопка со стрелкой в левом верхнем углу — **выход с озера**, соседняя — пауза. **Esc** или **M** открывают паузу, на Android работает системная кнопка «Назад».

## Озёра

| Озеро | Что происходит | Рыба |
| --- | --- | --- |
| Лесное озеро | закат, птицы | окунь, щука, лещ |
| Горное озеро | заснеженные вершины | форель, хариус, голец |
| Тростниковый залив | камыши, светлячки | карась, линь, лещ |
| Зимнее озеро | снегопад, льдины | сиг, налим, корюшка |
| Лунное озеро | звёзды, луна, светлячки | сом, угорь, жерех |
| Туманное болото | густой туман, кувшинки, ивы | вьюн, ротан, золотой карась |
| Дождливая бухта | ливень, круги на воде, гроза | судак, плотва, язь |
| Горячие источники | пар над каменными террасами | тилапия, кои, золотая рыбка |
| Тропическая лагуна | пальмы, чайки, бирюзовая вода | рыба-клоун, хирург, барракуда |
| Багряный лес | листопад | радужная форель, голавль, лосось |
| Северное сияние | полярная ночь, снег, сияние | палия, нельма, осётр |

У каждого озера своя музыка и звуки окружения (ветер, птицы, сверчки, лягушки, дождь, прибой). В воде видны круги от заброса, поклёвки и дождя, а вдали иногда выпрыгивает рыба.

## Удочки

Двенадцать снастей: три стартовые и девять для покупки. Удочки отличаются дальностью заброса, скоростью вываживания, устойчивостью к рывкам и предельным весом трофея. Удилище в кадре гнётся под нагрузкой рыбы.

## Звук

Музыка, атмосфера и эффекты создаются процедурно скриптом [`tools/generate_audio.py`](tools/generate_audio.py) (нужны `numpy` и `scipy`):

```
python3 tools/generate_audio.py            # всё
python3 tools/generate_audio.py sfx        # только эффекты
python3 tools/generate_audio.py ambient    # только атмосферу озёр
python3 tools/generate_audio.py music      # только музыку новых озёр
```

Громкость музыки, эффектов и атмосферы настраивается отдельно на странице «Настройки».

## Структура проекта

- `main.gd` — цикл рыбалки, удочка, леска, сохранения.
- `scripts/scenery.gd` — озеро, берега, причал, деревья, погода и оживление мира.
- `scripts/fish_model.gd` — процедурная 3D-модель рыбы и её анимация.
- `scripts/menu.gd` — меню, магазин, коллекция, настройки, пауза.
- `scripts/game_data.gd` — данные озёр, рыб и удочек.
- `shaders/` — вода с рябью, северное сияние, снег на горах, круглая маска превью.

## Android и Google Play

В проекте настроен профиль экспорта **Android Play**: формат Android App Bundle (`.aab`), 64-битные ARM-сборки, минимальный Android API 24 и целевой API 36. Для сборки нужны Godot 4.7.2, Android SDK, JDK 17 и Android build template этой же версии Godot. Выберите этот профиль в Godot и экспортируйте релизный AAB; ключ загрузки находится отдельно от исходников и должен быть надёжно сохранён.

Подробные шаги установки SDK, экспорта и загрузки пакета описаны в [ANDROID_BUILD.md](ANDROID_BUILD.md). Идентификатор пакета `com.quietlake.fishing` — временный: перед созданием приложения в Play Console замените его на уникальный идентификатор своего издателя, если он уже занят.
