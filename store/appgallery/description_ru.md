# Huawei AppGallery (AppGallery Connect) — карточка приложения

**Название приложения:** Quiet Waters: Fishing
**Язык карточки:** русский (можно добавить английский)
**Категория:** Игры → Симуляторы
**Возрастная категория:** 3+ (заполните анкету рейтинга в AGC; в игре нет насилия, рекламы и покупок)
**Файл для загрузки:** `build/QuietWaters-appgallery.apk`
**Иконка:** `store/assets/icon_512.png` (512×512) и `icon_216.png` (216×216)
**Скриншоты:** `store/screenshots/*.png` (16:9, до 5 штук) — берите 01, 02, 03, 05, 06
**Промо-картинки:** `store/assets/banner_1280x720.png`, `banner_1024x480_aurora.png`
**Политика конфиденциальности:** текст в `store/privacy_policy_ru.md`, опубликуйте по ссылке
**Сервисы Google/HMS:** не используются, игра работает на устройствах Huawei без GMS

## Заметки по загрузке в AGC
1. «Мои приложения» → «Добавить приложение», платформа Android, тип «Приложение или игра», пакет `com.quietlake.fishing` (тот же, что в `export_presets.cfg`).
2. «Распространение» → «Информация о версии» → «Пакет приложения» → загрузите APK.
3. Заполните страницу «Информация о приложении», загрузите иконку, скриншоты и политику, пройдите анкету возрастного рейтинга.
4. Отправьте на проверку.
